# Prezentační web – Pracovní deník

Moderní prezentační web pro pracovní deník, optimalizovaný pro iPhone (Safari, safe-area, dotykové ovládání).

## Struktura
- `index.html` – obsah stránky (česky)
- `style.css` – responzivní styl, tmavý design
- `script.js` – drobné interakce

## Spuštění
Otevřete `index.html` v prohlížeči, nebo hostujte přes GitHub Pages (Settings → Pages → branch `main`, složka `/web`).
